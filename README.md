# 智慧自习室预约与管理系统

基于 Python、FastAPI、SQLite 和 uv 构建的预约管理工作台，默认通过本地 `8000` 端口运行。

## 启动

```powershell
uv sync
uv run uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```

浏览器打开 http://127.0.0.1:8000 。首次启动会自动创建 `app/study_room.db` 和演示数据。

管理员演示账号：`admin` / `admin123456`；学生演示账号使用学号登录，默认密码为 `123456aa`。完整账号清单保存在本地 `docs/accounts.md`，其中包含密码，因此不纳入版本控制；CSV 导入格式见 `docs/students.csv.example`。

## 已实现

- 座位资源状态与属性管理
- 用户、管理员预约创建与状态管理
- 签到、签退、取消预约、自动违约记录
- 学生用户中心、黑名单原因通知与解封倒计时
- 投诉建议与关联座位报修、本人处理进度与管理员回复
- 履约信用分与违约记录页，按预约履约行为自动计算
- 座位数量统一取自实体座位，教室容量与开放状态自动汇总
- 座位报修、维修中暂停预约、维修完成恢复可用的完整流程
- 手动违约登记、履约信用自动扣分与受限账号解封日期管理
- 迟到签到自动违约、早退时长记录和 90 天信用分自动恢复
- 按座位查询预约记录、座位搜索筛选和热门座位/爽约率分析
- 柱状图、折线图、统计数据，每 10 秒自动刷新
- 功能文档对照审查见 `docs/requirements-review.md`
- Git 分支、合并与推送流程记录见 `docs/git-pr-flow.md`
