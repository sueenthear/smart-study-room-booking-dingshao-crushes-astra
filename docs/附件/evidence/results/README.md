# 证据运行输出

每次跑完 `repro.ps1` 或 `db_checks.sql`，把输出存成：

```
results/YYYYMMDD_场景.txt
```

例：`results/20261101_并发同座位.txt`、`results/20261101_库核对.txt`。

## 为什么必须留文件

`02` 的 A.6 表"实际结果"一列要写文件名，A.7 的"发现依据"也要指向这里。老师抽查时点开一个 txt 就能看到当时的返回码与数据库快照，比正文里一句"已实测"有用得多。

## 建议同时在文件头部记三行

```
时间：2026-11-01 16:20
环境：本机 uvicorn，库为 app.db 的副本
操作者：【姓名】
```

## 清场

脚本会往库里写预约、改状态。跑完用跑前的数据库副本覆盖回去，并在结果文件末尾写一句"已回滚到 <副本名>"，避免演示时数据对不上。
