## 来源与导出方式

- 会话：DeepSeek Harness 桌面版，会话 ID `43146252-24bb-42da-9cf4-6623d6f21840`，日志 `session.v4.jsonl.zstd`（1992 条记录，解压 6.7 MB）。
- 导出：zstd 是分帧追加的，先按 `28 B5 2F FD` 定帧边界逐帧解压，再取 `user/message` 与 `assistant/message` 的正文，按任务切段。
- **没有改写原话**，只有截断；截断处写"……（此处节选）……"，删工具调用处写"……（删去 N 次工具调用与中间输出）……"。
- 时间戳按 Asia/Shanghai 换算，保留到分钟。

## 为什么是节选

完整会话里 282 次工具调用占大头（写文件、渲图、跑转换），对核对"人怎么质疑、AI 怎么改"没有信息量。节选只保留人与 AI 的往返和决策点。
