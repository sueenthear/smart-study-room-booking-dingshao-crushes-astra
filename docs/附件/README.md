## 当前口径：纸面原型，不是实机截图

A.6 走的是**纸面原型**路线（课程允许：「纸面原型应提供页面材料及查看顺序」）。因此：

- A.6 的结论一律写「通过，页面流程走查」，**不写**「通过，功能验证」；
- 页面材料在 `prototypes/`（P0—P5 六页 + README 里的查看顺序），源文件是 `图源_原型页面.pptx`；
- 并发、越权、超时释放这些结论来自**代码与表结构核对**（`evidence/`），不来自原型图；
- 如果以后补实机走查：新建 `screenshots/`，同时把 02 的 A.6 结论口径、04 的 E-04 定义一起改，别只换图。
