# 智慧自习室预约与管理系统环境清单

> 文档日期：2026-11-08
> 适用范围：本地开发、课堂演示和功能验证
> 项目目录：仓库根目录 `smart-study-room-booking-dingshao-crushes-astra`

## 1. 环境概览

本项目是单体 Python Web 应用：FastAPI 同时提供页面、静态资源和 JSON API，SQLite 作为本地数据库，前端使用原生 HTML、CSS 和 JavaScript。项目不需要 Node.js 构建，也不需要独立数据库服务。

| 项目 | 要求 | 本项目验证环境 |
| --- | --- | --- |
| 操作系统 | Windows、Linux 或 macOS | Windows 11 专业版 64 位 |
| Python | `>=3.11`，以 `pyproject.toml` 为准 | Python 3.13.14 |
| uv | 建议使用当前稳定版 | uv 0.12.1 |
| SQLite | Python 标准库自带 | SQLite 3.53.1 |
| 浏览器 | 支持 Fetch API 和 CSS Grid 的现代浏览器 | Chrome/Edge 等现代浏览器 |
| 端口 | 默认 `8000`，可改用其他空闲端口 | 开发验证使用 `8765` 临时端口 |
| Node.js | 非运行依赖，仅用于检查前端 JavaScript 语法 | Node.js 24.16.0、npm 11.13.0 |
| Git | 仅在拉取、提交、推送和发布时需要 | Git 2.55.0.windows.3 |

## 2. Python 运行依赖

依赖声明位于 `pyproject.toml`，完整锁定版本位于 `uv.lock`。安装时应执行 `uv sync`，不要在项目目录外混用其他虚拟环境。

| 依赖 | 声明范围 | 当前锁定版本 | 用途 |
| --- | --- | --- | --- |
| `fastapi` | `>=0.115.0,<1.0.0` | 0.142.2 | HTTP 路由、请求模型和应用入口 |
| `uvicorn[standard]` | `>=0.30.0,<1.0.0` | 0.54.0 | ASGI 开发与运行服务器 |
| `python-multipart` | `>=0.0.9,<1.0.0` | 0.0.32 | CSV 文件上传表单解析 |
| `pydantic` | FastAPI 传递依赖 | 2.13.5 | 请求数据校验 |
| `starlette` | FastAPI 传递依赖 | 1.7.0 | ASGI Web 框架基础能力 |

`uvicorn[standard]` 可能会安装 `httptools`、`watchfiles`、`websockets` 等可选依赖。Windows 通常可以直接使用预编译包；如果安装失败，优先升级 uv 和 Python，而不是手工降级项目依赖。

## 3. 系统与硬件建议

### 最低配置

- 双核 CPU
- 4 GB 内存
- 500 MB 可用磁盘空间
- 可访问 PyPI，用于首次安装依赖
- 8000 端口可用

### 推荐演示配置

- 四核及以上 CPU
- 8 GB 及以上内存
- 1 GB 可用磁盘空间
- 1920x1080 或更高分辨率；浏览器缩放 100%
- 可访问 `unpkg.com`，用于加载页面图标

应用本身资源占用较低，当前演示数据库只有几十 KB。资源消耗主要来自 Python 运行时、浏览器页面和开发模式文件监听。

## 4. 端口与网络

| 项目 | 默认值 | 说明 |
| --- | --- | --- |
| 应用监听地址 | `127.0.0.1` | 仅本机访问 |
| 应用端口 | `8000` | 与 `README.md`、`Start.bat` 保持一致 |
| 数据库文件 | `app/study_room.db` | 首次启动自动创建 |
| 前端静态目录 | `app/static/` | 由 FastAPI 挂载到 `/static` |
| 外部资源 | `https://unpkg.com/lucide@latest` | 加载 Lucide 图标；离线时页面主体可用，但图标可能缺失 |

如果 `8000` 被占用，可使用其他端口：

```powershell
uv run uvicorn app.main:app --host 127.0.0.1 --port 8080 --reload
```

访问地址相应改为 `http://127.0.0.1:8080/`。

## 5. 配置项

项目当前没有 `.env` 或环境变量配置：

- 没有数据库连接串，数据库路径硬编码为 `app/study_room.db`。
- 没有生产环境密钥、对象存储或第三方 API 配置。
- 管理员账号和演示学生账号由代码及初始化数据提供。
- 前端登录状态保存在浏览器 `localStorage` 的 `studySession` 键中。
- 数据库、虚拟环境和缓存文件已在 `.gitignore` 中排除。

因此，复制代码后只需安装 Python 依赖即可运行。演示账号清单见 `docs/accounts.md`，这些账号仅限本地演示。

## 6. 安装与启动

### 首次安装

```powershell
uv sync
```

### 开发模式启动

```powershell
uv run uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```

浏览器打开 <http://127.0.0.1:8000/>。

### Windows 快速启动

双击 `Start.bat`，或在 PowerShell 中执行：

```powershell
.\Start.bat
```

该脚本不启用热重载，适合课堂演示；修改后端代码后需要重新启动。

### 首次启动行为

首次启动时会自动：

1. 创建 `app/study_room.db`。
2. 创建 `classrooms`、`rooms`、`users`、`bookings`、`complaints`、`violations` 表。
3. 执行兼容性字段检查，为旧数据库补齐新增列。
4. 在空数据库中写入教室、座位、用户、预约、投诉和违约演示数据。
5. 同步教室容量、用户信用分和违约历史。

### 重置演示数据

先停止服务，再删除本地数据库；下次启动会重新生成数据和表结构。

```powershell
Remove-Item -LiteralPath .\app\study_room.db
uv run uvicorn app.main:app --host 127.0.0.1 --port 8000 --reload
```

该操作会清除本地修改，仅在确认不需要现有数据时执行。

## 8. 验证命令

```powershell
node --check app/static/app.js
uv run python -m py_compile app/main.py
git diff --check
```

启动后的基础检查：

```powershell
Invoke-WebRequest -UseBasicParsing http://127.0.0.1:8000/
Invoke-RestMethod http://127.0.0.1:8000/api/overview
```

预期结果：

- `/` 返回 HTTP 200。
- `/api/overview` 返回座位总数、开放座位、使用中座位、预约数、学生数、违约数和待处理投诉数。
- 浏览器可打开登录页，并能切换学生登录和管理员登录。

## 9. 常见问题

| 现象 | 原因 | 处理方式 |
| --- | --- | --- |
| `uv` 不是可识别命令 | uv 未安装或未加入 PATH | 安装 uv，重新打开终端后执行 `uv --version` |
| Python 版本不符合要求 | Python 低于 3.11 | 安装 Python 3.11 或更高版本，执行 `uv python list` 检查 |
| 端口已被占用 | 其他进程占用了 8000 | 改用 `8080` 等空闲端口 |
| 修改后端代码无效果 | 启动时没有 `--reload` | 重启服务，或开发时使用 `--reload` |
| 图标不显示 | 无法访问 `unpkg.com` | 检查网络；业务功能不依赖该 CDN |
| 数据库锁或初始化异常 | 多进程同时初始化同一个 SQLite 文件 | 只启动一个应用进程，不要同时使用多个 Uvicorn worker |
| 页面显示旧脚本 | 浏览器缓存了静态资源 | 强制刷新页面；静态资源已使用版本查询参数 |

## 10. 生产部署提示

当前项目定位是课程演示，不建议直接用于生产。正式部署前至少需要处理：

1. 增加服务端会话、访问令牌和角色鉴权。
2. 使用密码哈希，移除明文密码和公开演示账号。
3. 为预约冲突增加数据库级约束和事务保护。
4. 将 SQLite 替换为支持并发写入的数据库，或严格限制单进程访问。
5. 明确反向代理、HTTPS、日志、备份、监控和数据保留策略。
6. 为管理员接口、CSV 导入和文件上传增加权限检查及安全限制。

## 11. 当前环境结论

在 Windows 11、Python 3.13.14、uv 0.12.1 环境下，项目已验证可以完成依赖解析、Python 编译检查、JavaScript 语法检查、应用启动、首页访问、总览接口访问和管理员登录。该环境满足本地开发和课堂演示要求。
