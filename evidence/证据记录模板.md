# 证据记录模板（复制本文件内容到 TC-xxx.txt）

> 每条测试一个 txt 文件，文件名与案例编号对应，如 `TC-P01.txt`。
> 优先用命令重定向保存文字结果；图片只能作补充，不能单独当证据。

## 模板（复制以下全文到新建的 txt）

```text
案例编号：TC-__
测试目标：__
代码版本：__（commit 号；或版本标签 + 日期，如 1.1 / 2026-11-26）
环境：Python __、uv __、SQLite 文件 __
执行人：__　　日期：__

命令：
（粘贴实际执行的命令原文；若为手工操作，写清每一步）

文字结果：
（粘贴完整原始输出，不要只写"通过"）
（若手工操作，写响应码、响应体、数据库查询结果）

截图：evidence/TC-__.png（如有）
截图说明：__（拍的是什么，何时拍的）

预期出处：01_需求规格说明书.md 的 AC-__ / BR-__ / ST-__ / NFR-__
实际是否符合预期：符合 / 不符合
（不符合时到 判责记录.md 填判定类型）
```

## 命令重定向速查

**Git Bash：**
```bash
uv run python -m unittest tests.test_security_and_concurrency -v > evidence/TC-P02.txt 2>&1
```

**PowerShell：**
```powershell
uv run python -m unittest tests.test_security_and_concurrency -v *> evidence\TC-P02.txt
```

> `2>&1` / `*>` 表示把错误输出也一并存入文件，保证原始结果完整。

## 图片处理规则

1. 图片文件与 txt 同名同编号：`TC-P01.png` 配 `TC-P01.txt`
2. txt 里必须写清图片拍的是什么、什么时候拍的
3. 图片不能替代文字结果；没有命令/环境/版本信息的截图不算证据
