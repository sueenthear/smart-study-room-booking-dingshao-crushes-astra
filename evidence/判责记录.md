## 判定类型速查

| 类型 | 含义 | 处理方式 |
| ---- | ---- | -------- |
| 实现不符 | 代码行为与已确认预期不一致 | 打回实现者改代码，测试不改 |
| 预期写错 | 预期本身与任务书/规格说明书不符 | 写清依据，经业务责任人书面批准后才改测试 |
| 需求冲突 | 规则本身矛盾或歧义 | 重开 Q，暂停相关案例 |
| 文档过时 | 代码已实现但文档标未实现/未验证 | 更新文档状态，测试责任人复核 |
