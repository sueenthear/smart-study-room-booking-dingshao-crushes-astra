## TC-S01 / 签到窗口下限（开始前 30 分钟）

| 字段 | 内容 |
| --- | --- |
| 预期出处 | **ST-03**（签到窗口：开始前 30 分钟至结束时间） |
| 测试目标 | 验证过早签到是否被拒绝 |
| 前置数据 | 创建一条预约：`start_at` = 当前时间 + 40 分钟，`end_at` = +90 分钟；用学生 token |
| 操作 | 立即 PATCH `/api/bookings/{id}/status?status=checked_in` |

| 备注 | 代码 `update_booking_status` 只检查了 `now >= end_at`，未检查开始前 30 分钟下限，预计此条会判实现不符 |
