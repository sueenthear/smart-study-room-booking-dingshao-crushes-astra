# evidence/ 证据目录说明

> 依据：《架构设计后确认与分阶段实现操作指引》第十二节"精选证据"

## 本目录放什么

| 文件 | 内容 | 责任人 |
| --- | --- | --- |
| `判责记录.md` | 测试失败的判责结论与派工 | 郑晨宇 |
| `审查记录.md` | 交叉审查结论（通过/需修改/待核验） | 郑晨宇 |
| `TC-xxx.txt` | 单个测试案例的原始运行结果 | 执行人 |
| `阶段验收_S1.md` | 阶段验收单 | 郑晨宇 + 王锦添 |

## 每条原始结果必须包含四样

1. **代码版本**：commit 号，或版本标签 + 日期（如 `1.1 / 2026-11-26`）
2. **环境**：Python 版本、uv、SQLite 文件位置
3. **命令**：实际执行的命令原文
4. **原始输出**：完整结果，不要只贴"通过"两个字

## 原则

- 截图不能单独当"已验证"证据
- 精选，不要全堆；优先保留并发/权限/异常/判责/交叉审查/AI 纠错案例
- 聊天记录不算记录，必须落成文件
